# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Resumen

- Sé respetuoso/a y constructivo/a; critica las ideas, no a las personas.
- Acepta las críticas técnicas con apertura y asume buena fe.
- No se tolera el acoso, la discriminación ni los ataques personales.

## Aplicación

Los comportamientos inaceptables pueden reportarse a la persona mantenedora por correo
(angelsanta1@gmail.com). Se revisarán todas las quejas de forma confidencial y se responderá en un
plazo razonable. Quien incumpla este código puede ver sus contribuciones rechazadas o ser vetado/a del proyecto.
